# Unisoc TS10 Launcher

Android launcher for automotive/multimedia systems.

## Compatibility

- Minimum SDK: API 19 (Android 4.4 / KitKat)
- Target SDK: API 19
- Language: Java
- No AndroidX dependency
- Designed for landscape automotive displays

## Planned features

- Full Android launcher/home-screen behavior
- App drawer and application search
- Folders and shortcuts
- Android App Widgets
- Persistent desktop/layout management
- Automotive-friendly home screen
- Embedded navigation area/provider architecture
- Day/night UI
- Settings and customization

The project intentionally remains API 19 compatible.
